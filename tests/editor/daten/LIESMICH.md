# Testdateien von LibreOffice

Alle Dateien hat `soffice --headless --convert-to` aus eigenen, einfachen Testbildern erzeugt (rotes Feld, blauer Kreis, Text „Hallo“;
ein Bild mit Markierung „dekorativ“). Sie dienen dazu, Lunivos Leser und Schreiber an echten Dateien eines anderen Programms zu prüfen.

- `libreoffice.emf`, `libreoffice.wmf`: Metafiles
- `libreoffice_svg.odt`, `libreoffice_svg.docx`: Bild mit SVG und PNG-Ersatz
- `libreoffice_dekorativ.odt`: Bild mit `loext:decorative="true"`
